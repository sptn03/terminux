# Security Rules


==================================================

# Secrets


Never:

- commit keys
- expose tokens
- log passwords


==================================================

# User Input


Always validate:

- API input
- forms
- files
- external data


==================================================

# Authentication


Check:

- identity
- permission
- ownership


==================================================

# Database


Avoid:

- unsafe queries
- unescaped input


==================================================

# File Handling


Check:

- path traversal
- size limit
- extension


==================================================

# Dependencies


Before adding:

Check:

- necessity
- security
- maintenance
